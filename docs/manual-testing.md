## 1. 安装与原生页面

- [ ] 从 `dist` 或 ZIP 解压目录加载；扩展管理页无错误。
- [ ] 刷新已有 ChatGPT 标签后，左侧显示「整理空间」，已有对话页面显示右侧问答导航。
- [ ] 工具栏图标和面板设置按钮均能打开设置与备份页。
- [ ] 原生侧栏、新建聊天、搜索聊天、项目入口、输入框和发送操作仍可使用。
- [ ] 切换浅色 / 深色，文字、选中状态、菜单与输入框均可辨认。
- [ ] 收起原生侧栏，以及缩窄窗口时，浮动入口可用，面板不会挡住输入框。
- [ ] 无刷新切换不同聊天、浏览器后退 / 前进后，不重复出现插件面板，不残留上一会话的问答。
- [ ] 重新加载扩展后刷新网页，数据恢复且只挂载一套界面。

记录真实 ChatGPT 的页面结构差异，例如消息角色或侧栏区域不能识别。若只测过模拟网页，本节不得标为真实网页通过。

## 2. 文件夹与标题搜索

- [ ] 创建三级目录；尝试第四级应被阻止，现有数据不变。
- [ ] 重命名、展开 / 折叠；刷新后文件夹及折叠状态保留。
- [ ] 把原生侧栏中已加载的聊天拖入文件夹，标题正确且可以打开。
- [ ] 在未打开该聊天的情况下，从已收录列表菜单归类；每条对话只有一个归属。
- [ ] 使用「整理当前对话」移动到另一文件夹，再移回未分类。
- [ ] 文件夹拖拽换父级、上 / 下边缘排序均正确；菜单上移、下移和移动可完成同样操作。
- [ ] 将文件夹移入自身、后代或导致超过三级的位置，应被拒绝。
- [ ] 搜索已收录标题，结果显示正确归属；清空搜索恢复文件夹树。
- [ ] 搜索时输入光标不丢失；后台状态更新不会关闭正在编辑的名称或移动弹窗。
- [ ] 点击聊天标题可正常打开，Ctrl / Cmd 点击可以使用浏览器原生新标签行为。
- [ ] 删除包含子目录和聊天的测试文件夹：确认框数量正确；取消不改变数据；确认后聊天回到未分类，ChatGPT 原聊天仍可打开。
- [ ] 同时打开两个 ChatGPT 标签，各创建或移动不同条目；两个标签最终看到全部修改，刷新后仍保留。

## 3. 问答时间轴与正文搜索

- [ ] 短对话中，每轮问题对应一个节点；悬停预览与点击定位正确。
- [ ] 展开问题目录，当前阅读位置随滚动变化，点击后短暂高亮目标问答。
- [ ] 搜索问题或回答中的关键词，匹配片段和点击目标一致。
- [ ] 对话包含重复问题或相似段落时，不跳到错误的另一轮。
- [ ] 回答流式生成时，目录更新但不抢输入焦点、不重复新增节点。
- [ ] 编辑问题或重新生成回答后，只导航当前显示分支，不残留隐藏分支节点。
- [ ] 较长对话向上加载历史消息后，已读取数量和搜索结果更新。
- [ ] 页面卸载旧消息或使用虚拟列表时，不把不存在的 DOM 目标伪装成跳转成功。
- [ ] 新建但尚无持久会话地址的页面正常显示；不把临时地址记成可长期打开的对话。
- [ ] 在长回答、代码块、图片 / 附件消息、多个连续助手段落中检查分组及导航。

正文搜索只覆盖当前已读取内容。没有加载过的内容未命中属于范围限制，但界面必须明确说明，不能显示“已搜索全部历史”。

## 4. 备份与恢复

- [ ] 导出 JSON，确认包含文件夹、归类、已收录标题及设置。
- [ ] 检查备份不含问答正文、Cookie、登录凭证。
- [ ] 导入之前显示新增 / 跳过数量；取消预览不修改数据。
- [ ] 导入新记录后结构和归类正确；再次导入同一备份不产生重复记录。
- [ ] 同 ID 的本机记录保留，导入不会替换本机同步开关或界面设置。
- [ ] 非 JSON、错误版本、重复 ID、循环层级、超深文件夹及非法网址的备份整批拒绝，本机数据不变。
- [ ] 超过导入大小限制的文件被拒绝，仍可继续正常使用。
- [ ] 在新建的测试浏览器配置中导入备份，分类能打开原对话；账号访问条件另行核对。

卸载或清理扩展数据前，先导出备份。测试卸载恢复时只使用专门的测试配置，避免丢失日常使用的数据。

## 5. 同一浏览器的双设备同步

以下步骤必须在 **Chrome ↔ Chrome** 和 **Edge ↔ Edge** 分别执行和记录，不得相互代替；没有第二台设备或同账号同步条件时，明确标为未验证。

### 前置条件

- [ ] 两端分别手动安装同一构建，扩展 ID 完全一致；固定 `manifest.key` 未被修改。
- [ ] 两端登录同一个浏览器账号，浏览器的扩展相关同步已开启；插件同步开关开启。
- [ ] 两端均处于联网状态，记录浏览器版本和开始时间。

### 到达与一致性

- [ ] A 端创建测试文件夹并归类一条对话；B 端实际看到文件夹、正确标题和归类。
- [ ] B 端重命名文件夹、移动对话；A 端实际收到变化。
- [ ] A 端删除含子文件夹的测试目录；B 端没有恢复已删除目录，对话回到未分类。
- [ ] 两端关闭并重启浏览器后，分类仍一致。
- [ ] 两端离线时分别修改不同条目，恢复联网后两端都保留这些修改。
- [ ] 两端离线修改同一条目后恢复联网，最终收敛到同一结果，不反复跳变。
- [ ] 离线设备保留旧数据后重新上线，不使已删除分类复活。
- [ ] 未分类标题索引没有自动出现在另一设备；问答正文没有被同步。

### 状态真实性

- [ ] 设置页显示「已交给浏览器同步」时，只记录为本机提交；必须看到 B 端实际数据后才记到达成功。
- [ ] 暂停插件同步后，本机仍可整理；恢复同步后待提交修改继续处理。
- [ ] 关闭浏览器账号同步时，插件不宣称其他设备已收到数据。
- [ ] Chrome 与 Edge 之间不宣称账号同步互通；跨浏览器迁移使用 JSON。

## 6. 配额、故障与网页改版

本节的故障注入应在独立测试配置中进行，避免耗尽日常账号同步空间。可结合自动化测试记录，注明哪些情况只在受控模拟中验证。

- [ ] 同步达到总容量、单项或条目数限制时，本地数据保留，界面显示可理解的错误。
- [ ] 写入限流或暂时失败后，待同步队列保留并可重试，不出现持续高频写入。
- [ ] 后台 Service Worker 停止 / 重启后，已提交的本地修改不丢失，队列可以恢复。
- [ ] 同步故障时仍能导出备份、搜索标题和使用问答导航。
- [ ] 文件夹树接收乱序或暂缺父节点的远端变更后，不永久丢弃后到的归类数据。
- [ ] ChatGPT 页面选择器变化时，插件能避免错误归类或跳到另一聊天；记录具体失效区域和浏览器版本以便修复。
