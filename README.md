# ChatGPT 整理空间

<img src="assets/icons/icon128.png" alt="ChatGPT 整理空间图标" width="72" height="72">

**v0.1.3 · Chrome / Edge 桌面浏览器扩展**

用文件夹整理对话，用右侧时间轴回到某轮问答。中文界面，沿用 ChatGPT 的原生配色与浅色或深色主题，适合在一个浏览器配置中使用单一 ChatGPT 账号。

这是独立实现的个人版插件，交互参考 [Voyager](https://voyager.nagi.fun/en/guide/timeline.html)，与 OpenAI、ChatGPT 或 Voyager 官方无隶属关系。

[查看界面预览与验证记录](docs/verification.md)。核心版本已完成 34 项单元测试与 Chrome 测试版、Edge 各 4 项本地模拟页面场景；v0.1.2 的侧栏遮挡修复已通过 34 项单元测试及 Chrome 测试版、Edge 各 2 项界面回归场景；v0.1.3 接入新版图标。真实登录态网页和双设备账号同步尚未验证。

## 安装

从 GitHub 获取可安装版本：打开 [Releases](https://github.com/chiiiiiiing/chatgpt-organizer/releases/tag/v0.1.3)，在 **Assets** 中下载 `chatgpt-organizer-0.1.3.zip`。GitHub 自动提供的 `Source code (zip)` 只是源码，需要自行构建后才能安装。

[隐私说明](PRIVACY.md) · [Edge 商店上架指南与可复制填写内容](docs/edge-publishing.md)

### 使用已经构建好的文件

1. 如果拿到的是 `release/chatgpt-organizer-0.1.3.zip`，先解压到一个准备长期保留的文件夹。不要直接选择 ZIP。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开页面上的「开发者模式」，选择「加载已解压的扩展程序」。
4. 选择包含 `manifest.json` 的文件夹：本项目直接选择 `dist`；ZIP 则选择解压后包含该文件的目录。
5. 打开 [ChatGPT](https://chatgpt.com/)，或者刷新已经打开的 ChatGPT 页面。

左侧出现「整理空间」、对话页面右侧出现问答导航后，即可开始使用。安装后请保留所选文件夹；移动或删除它可能使扩展无法加载。

工具栏里的插件图标可以打开设置与备份页，也可以点「整理空间」标题右侧的设置按钮。

### 更新插件

先在设置页导出 JSON 备份。将新构建覆盖到原安装目录，在扩展管理页点击该扩展的「重新加载」，再刷新 ChatGPT 页面。尽量保留同一安装位置和扩展 ID，不通过卸载再安装来更新。

## 使用

### 整理对话

- 点击「整理空间」旁的 `＋` 创建文件夹；文件夹菜单可新建子文件夹、重命名、移动、上移、下移和删除，最多支持三级。
- 把 ChatGPT 原侧栏中的对话链接拖到文件夹上，或点「将当前对话移入文件夹」。已收录的对话也可以通过自身菜单选择目标位置。
- 每条对话只能归属一个文件夹；选「未分类」可以解除归类。
- 文件夹可拖动调整层级和顺序；拖到另一文件夹的中间区域表示移入，靠近上边缘或下边缘表示排序。菜单提供相同操作，触控板或键盘使用时也可完成整理。
- 删除文件夹前会显示受影响的子文件夹和对话数量。确认后，相关对话回到「未分类」，**ChatGPT 上的原始聊天不会被删除**。

### 搜索与回看

- 左侧搜索框搜索**已收录对话的标题**。侧栏加载过或你打开过的对话会逐步进入本机索引，不会后台扫描全部聊天历史。
- 右侧时间轴每个节点对应一轮问题。悬停预览，点击跳转并短暂高亮；也可以展开为问题目录，搜索当前对话的问题和回答。
- 目录和正文搜索以**当前页面已读取、仍可定位的消息**为范围。较早的内容可能需要向上滚动加载；插件不会把尚未加载的历史当作已搜索。
- 编辑问题或重新生成回答后，导航跟随当前显示的分支；不会显示其他隐藏分支的完整历史。
- 左右面板均可收起。窄窗口通过浮动面板使用，设置页可以关闭时间轴或默认展开问题目录。

本版本**没有收藏功能**，也不包含提示词库、问答笔记、AI 自动分类或完整聊天导出。

## 同步与备份

### 浏览器账号同步

启用后，同步的内容是文件夹、归类关系，以及已归类对话的标题和地址。未归类标题索引只保存在本机；问答正文仅用于当前页面导航和搜索，不持久保存，也不上传。

要在两个设备之间同步：

1. 两端分别手动安装同一份插件；本插件不会自动安装到另一台设备。
2. 两端使用同一种浏览器，登录同一个**浏览器账号**，并在浏览器设置中打开扩展相关同步。仅登录同一个 ChatGPT 账号并不足以同步插件数据。
3. 核对扩展管理页面中的扩展 ID 一致。本项目已固定 `manifest.json` 中的 `key`；更新或自行构建时请保留它。
4. 在插件设置页启用「浏览器账号同步」，然后在另一设备实际查看分类是否到达。

Chrome 与 Edge 使用各自的同步服务，**两种浏览器之间不直接互通**，可通过 JSON 备份迁移。Edge 的双设备数据往返需要单独验证；不能把浏览器支持安装扩展当作同步已经通过。

设置页的状态含义：

| 状态 | 含义 |
| --- | --- |
| 本地已保存 | 数据已经保存在当前设备 |
| 待提交 | 当前设备还有记录等待写入浏览器同步区 |
| 已交给浏览器同步 | 本机浏览器接收了记录；不代表其他设备已经收到 |
| 同步需要处理 | 查看错误提示，本地整理数据仍保留 |

浏览器未开启账号同步时，`storage.sync` 也可能只保存在本机。插件没有远端确认机制，请以第二台设备的实际结果为准。关闭插件同步开关不会删除已有的浏览器云端副本。

Chrome 扩展同步区的限制约为 **100 KB 总量、8 KB 单条记录、512 条记录**，并限制写入频率。删除标记也占用空间。设置页会显示已使用容量；触及限制时不会静默丢弃本地分类，可先导出备份。详见 [Chrome 存储文档](https://developer.chrome.com/docs/extensions/reference/api/storage)。

### JSON 备份与导入

1. 打开设置页，点击「导出备份」，保存下载的 JSON 文件。
2. 在目标浏览器中点击「导入 JSON」，选择文件并核对新增数量。
3. 点击「确认合并」后，新记录加入现有数据；相同 ID 的记录保留本机版本。

备份包含文件夹、归类、已收录标题索引和界面设置，**不包含问答正文、Cookie 或登录凭证**。导入采用合并方式，保留本机现有界面设置；不会因为备份中的设置而改变同步开关、面板状态等偏好。无效或版本不兼容的备份会被拒绝，不会只导入一部分。

备份文件含有对话标题和地址，请保存在自己的可信位置。**卸载插件、更换浏览器配置或清理扩展数据之前，先导出备份。**

## 使用边界与排查

- **单一 ChatGPT 账号**：本版本不自动隔离同一个浏览器配置中的多个 ChatGPT 账号或工作区。多账号请使用独立浏览器配置。
- **页面结构变化**：ChatGPT 改版可能影响标题识别、文件夹插入或问答定位。先刷新页面；仍有问题时可暂时禁用插件，原始聊天不受影响。
- **没有看到整理空间**：确认扩展已启用，当前地址为 `https://chatgpt.com/`，并刷新页面。收起原生侧栏或缩窄窗口时，查看浮动入口。
- **旧对话搜不到**：先在原生侧栏加载或打开该对话。标题索引不会自动覆盖账号全部历史。
- **正文关键词搜不到**：搜索只覆盖当前已读取的消息，向上滚动加载较早内容，并确认正在查看预期分支。
- **另一台设备看不到分类**：分别检查浏览器账号、浏览器同步开关、扩展 ID 和插件同步状态；设置页显示「已交给浏览器同步」不能替代双设备检查。
- **已归类聊天失效**：插件保存的是原聊天的引用；原聊天被删除或当前账号无权访问时，插件不会恢复其正文。

扩展只匹配 ChatGPT 网站，不使用自建服务器，不调用付费 API。浏览器账号同步使用浏览器自己的服务。

## 开发与验证

开发环境建议 Node.js 22.12+，本项目使用 npm 管理依赖。首次准备：

```sh
npm install
npx playwright install chromium
```

常用命令：

```sh
npm run build       # 类型检查并生成 dist
npm test            # 数据层、同步逻辑、网页适配测试
npm run test:e2e    # 加载构建产物进行浏览器端到端测试；先运行 build
npm run package     # 重新构建并生成 release ZIP 和安装说明
```

`npm run check` 单独执行 TypeScript 检查。构建后的扩展必须通过浏览器扩展管理页加载，不能仅打开本地 HTML 来验证内容脚本。当前打包脚本使用系统 `zip` 命令，适用于 macOS / Linux；Windows 可以在 WSL 中打包，或直接压缩 `dist` 内的文件后分发。

主要模块：

- `src/content/`：ChatGPT DOM 适配、左侧文件夹和右侧时间轴。
- `src/background/`：本机数据库、分类命令、备份与同步队列。
- `src/settings/`：设置、容量状态、JSON 导入导出。
- `src/shared/types.ts`：跨模块数据与消息契约。

自动化测试通过不能证明真实 ChatGPT 登录态兼容，也不能证明 Chrome / Edge 的账号同步已到达另一台设备。请按 [手动验收清单](docs/manual-testing.md) 记录浏览器版本、测试环境、实际结果和未验证项，再给出兼容性结论。
